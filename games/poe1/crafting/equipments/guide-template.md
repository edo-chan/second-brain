# Equipment Crafting Guide Template

Use this structure when adding a reusable equipment target. Remove sections
that do not apply; do not leave placeholders in a finished guide.

## Scope And Snapshot

- build or skill archetype;
- patch, league relevance, and verification date;
- ordinary, influenced, fractured, Essence, Veiled, Eldritch, or other pool.

## Target And Base

- exact base types and base percentile considerations;
- minimum and ideal item level;
- quality, links, sockets, influence, corruption, and Intangibility state;
- desired prefixes, suffixes, implicits, and their mod groups.

## Value Tiers

- minimum keep relative to the equipped item;
- strong state worth deterministic finishing;
- aspirational state worth expensive manipulation.

## Crafting Routes

For each budget route, state:

- starting item state;
- what each currency changes and preserves;
- eligible success outcomes and valid probability model;
- failure recovery path;
- spending cap and stop condition.

## Build And Market Check

- PoB delta under an unchanged configuration;
- lost attributes, resistances, sockets, and defenses;
- current finished-item price versus expected craft cost and variance;
- exact next action after each material random result.
