# PoE 1 Crafting Library

Use this directory for crafting knowledge shared across builds and leagues.
Patch-stamp any data that can change, and verify current currency wording and
market prices before recommending an irreversible or expensive step.

- [general.md](general.md) - shared item-state, affix-priority, safety, and
  buy-versus-craft rules.
- [methods.md](methods.md) - what each crafting method changes and preserves,
  including Allflame.
- [probability.md](probability.md) - modifier weights, multi-preview and
  repeated-attempt formulas, simulation boundaries, and expected cost.
- [equipments/ilvl-86-affixes.md](equipments/ilvl-86-affixes.md) - common
  item-level 86 equipment affixes and weights.
- [equipments/endgame-chaos-dot-staff.md](equipments/endgame-chaos-dot-staff.md)
  - target affixes, stopping points, completion routes, and odds boundaries for
  an endgame Chaos damage-over-time staff.

Add future equipment guides under `equipments/`. Each guide should define the
build goal, base and item-level requirements, affix sides and tiers, minimum
keep and aspirational states, safe next steps, live-price comparison, and the
probability model that is valid for the recommended method.
